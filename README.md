# ❤️ Heart Risk Assistant

A clinical decision support tool that predicts heart disease risk from patient data and provides an AI-generated explanation in German.

## 🚀 Live Demo
👉 [Open on Hugging Face](https://huggingface.co/spaces/Sopasua1/health-risk-assistant)

## 📋 Project
- **Course:** KI Anwendungen – ZHAW
- **Blocks:** ML Numeric Data + NLP
- **Model:** Random Forest Classifier
- **NLP:** OpenAI GPT-4o-mini

## 📁 Structure
- `app.py` – Gradio application
- `notebooks/` – EDA and model training
- `models/` – Trained model
- `data/` – Heart disease dataset
- `documentation.md` – Full project documentation

## ⚠️ Disclaimer
This tool is for educational purposes only and does not replace medical advice.
